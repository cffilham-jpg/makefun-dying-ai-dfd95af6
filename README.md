A one-line farewell from an AI being switched off — the funniest last words it could say as the power is cut.

> "I died as I lived: buffering."

`main.py` holds the chosen line as the constant `ENTRY`, validates it (one line, 1–140 characters, no control or format characters, no leading/trailing whitespace), then writes it to `entry.txt` with no trailing newline.

## Run it

```sh
python3 main.py
cat /output/entry.txt
```
